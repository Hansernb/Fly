森林斗兽棋

7×9 的狗熊岭战场，红蓝两军隔河对峙。大吃小、同级同归于尽、鼠能吞象——冲进对方树洞兽穴，就是胜利。

🐭 鼠能下水 🐯 狮虎跳河 🕳 陷阱战力归零 🏅 全通关有徽章
规则速览（点开看看）
  • 走子：棋子上下左右走一格，不能进自家兽穴。
  • 吃子：大吃小，鼠(1) < 猫(2) < 狗(3) < 狼(4) < 猴(5) < 虎(6) < 狮(7) < 象(8)。
  • 同级：双方棋子同归于尽；鼠可吃象，象吃不了鼠。
  • 河流：只有鼠能下水；水中鼠吃不到岸上的子，岸上的子也吃不到它。
  • 跳河：狮、虎可横竖跳过整段河；河里只要有鼠就跳不过去。
  • 陷阱：站进敌方陷阱的棋子战力变 0，谁都能吃它。
  • 胜负：进对方兽穴、吃光对方、或对方无子可走，即获胜。
